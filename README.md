# JavaScript Hangman Game

A responsive and keyboard-accessible Hangman game built with vanilla JavaScript.

## Features

- Random words grouped by category
- On-screen and physical keyboard controls
- Correct and incorrect guess feedback
- Progressive Hangman drawing
- Clear win and loss states
- Restartable game flow

## Built With

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- DOM events and state management
- Accessible live announcements
